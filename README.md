# AR Profile - React + Vite + Tailwind CSS

A modern, professional React application built with Vite and styled with Tailwind CSS.

## 🚀 Features

- ⚡ **Vite** - Lightning-fast build tool and development server
- ⚛️ **React 18** - Latest React features with JavaScript
- 🎨 **Tailwind CSS** - Utility-first CSS framework
- 📦 **Professional Structure** - Well-organized, scalable project layout
- ✨ **Clean JavaScript** - Simple and straightforward development

## 📁 Project Structure

```
src/
├── components/        # Reusable React components
├── pages/            # Page-level components
├── hooks/            # Custom React hooks
├── utils/            # Utility functions and helpers
├── types/            # Type definitions (JSDoc)
├── constants/        # Application constants
├── assets/           # Images, fonts, and other static assets
├── styles/           # Global styles and CSS
├── App.jsx           # Main App component
└── main.jsx          # Application entry point
```

## 🛠️ Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview production build:

```bash
npm run preview
```

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

## 🎨 Tailwind CSS

Tailwind CSS is pre-configured and ready to use. Import the global styles in your components:

```jsx
import "./index.css";
```

## 📚 Components

Example components are provided in `src/components/`:

- **Button** - Reusable button component with variants
- **Card** - Content card component

## 🪝 Custom Hooks

Custom hooks are located in `src/hooks/`:

- **useCounter** - Example counter hook

## 🚀 Getting Started

1. Edit `src/App.jsx` to customize your application
2. Create new components in `src/components/`
3. Add custom hooks in `src/hooks/`
4. Define types using JSDoc comments in `src/types/`
5. Use Tailwind CSS classes for styling

## 📦 Dependencies

- React 18+
- Vite 8+
- Tailwind CSS 4+
